# Demo course: Electricity & Simple Circuits (Grade 6)

Adds a ready-to-teach course to a running Nanoskool LMS: 2 chapters, 6 units (lessons, videos, an activity), 6 illustrations and a 6-question quiz. It is granted to Green Valley Public School and assigned to Grade 6 - A (teacher Rahul Menon).

With the API running (`npm run dev` in `server/`), open a new Terminal window and run:

    cd ~/Documents/"Nanoskool LMS"/nanoskool-lms/demo-content
    node add-course.mjs

Running it again replaces the course. `draw.py` regenerates the images (needs Python + Pillow).
